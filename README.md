# fuel-chopper

A standalone, USB-only command-line tool that finds the best price reported by
its fuel data source for a selected fuel type, then offers to simulate an iPhone
location 100–900 metres from that station.

This project is derived from [GeoPort](https://github.com/davesc63/GeoPort) and
is licensed under [GPL-3.0-only](LICENSE). See [NOTICE](NOTICE) for attribution.

## Disclaimers

- The script is generated by AI.
- Not a single line of it has been read by a human.
- Only tested on macOS with iPhone, both running OS version 26.x.
- Use it at your own risk.

## Quick start

### 1. Connect the device

- Connect your iPhone/iPad with a cable.
- Make sure [Developer Mode is enabled](https://github.com/davesc63/GeoPort/blob/main/README.md#developer-mode)
- Trust the computer from the device.

### 2. Call the chopper

```bash
uv sync
sudo .venv/bin/fuel-chopper --fuel U91
```

Choose a state and skip confirmation when needed:

```bash
sudo .venv/bin/fuel-chopper --state VIC --fuel Diesel --yes
```

The normal command keeps the simulated location active until Ctrl-C, which
clears it before exiting. To clear a prior simulated location directly:

```bash
sudo .venv/bin/fuel-chopper --stop
```

The `sudo .venv/bin/fuel-chopper` form is required on macOS for iOS 17 and
later. Other supported platforms can use `uv run fuel-chopper ...`.

- `--state` accepts `ACT`, `NSW`, `QLD`, `VIC`, or `WA`.
- `--fuel` accepts `E10`, `U91`, `U95`, `U98`, `Diesel`, or `LPG`.

### 3. Lock it

Open the app, select your fuel type, and lock the price

### 4. Get back

Go back to your terminal, press Ctrl-C, and your device's location will
continue to work as normal.
